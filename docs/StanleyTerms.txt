2. WHAT STANLEY DOES

Stanley answers questions about Skullgirls Mobile fighters inside Discord.
It works only through Discord slash commands:

  /fighter      shows a card for one fighter: rarity, element, character,
                signature abilities, minimum and maximum stats, portrait
  /wiki         returns the Skullgirls Mobile Fandom wiki URL for a page
  /alias list   lists the alternative names recorded for a fighter
  /credits      shows contributor credits and links to these Terms and to
                the Privacy Policy

A smaller set of management commands (/fighter-admin and /alias-admin) is
restricted to editors; see section 7.

Stanley does not read ordinary chat messages, does not use any of Discord's
privileged intents (Message Content, Server Members, Presence), and does not
store any information about people who only read its replies.
